# 基于RAG的个性化学习推荐系统 - 前端

## 项目简介
这是一个基于检索增强生成（RAG）技术的个性化学习推荐系统的前端项目，使用 Vue 3 + Vite + Element Plus 开发。

## 技术栈
- **框架**：Vue 3 (Composition API)
- **构建工具**：Vite 5
- **路由**：Vue Router 4
- **状态管理**：Pinia
- **UI组件库**：Element Plus
- **HTTP客户端**：Axios
- **图表库**：ECharts

## 功能模块
### 公共模块
- 用户登录/注册
- 角色跳转（根据角色自动跳转到对应首页）

### 普通用户模块
- 仪表盘（学习统计）
- 私有知识库（文档上传、管理）
- 公共内容（浏览公开文档）
- 内容公开申请
- 学习中心（学习进度、错题本）
- 个性化推荐（推荐知识点、学习路径）
- 用户画像
- RAG问答（核心功能）
- 个人中心

### 审核员模块
- 仪表盘
- 审核工作台（审核内容公开申请）
- 公共内容查看
- 个人工作台

### 管理员模块
- 仪表盘（系统统计）
- 用户管理
- 审核员管理
- 内容全局管理
- 审核管理
- 系统配置
- 系统审计
